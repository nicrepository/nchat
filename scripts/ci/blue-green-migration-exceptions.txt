# Migrations that predate the Blue/Green release policy of issue #626.

# These files have already been applied to running environments. The migration
# runner stores a SHA-256 of each file (scripts/db/migrate.sh migration_checksum)
# and refuses to continue when it changes, so annotating them in place would
# block every deployment that has already run them. The exception is recorded
# here instead, where it costs nothing and is just as visible in review.
#
# This list is closed. A migration written from now on declares a contract-phase
# operation in the file itself:
#
#     -- nchat:blue-green contract-phase <why this is safe now>
#
# Do not add entries to this list to get a new migration past the gate.
#
